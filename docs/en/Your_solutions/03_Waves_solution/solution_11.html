Task 11 · Section 3: Waves

Young's Double-Slit Interference

Slit separation d (px)
d = 80 px
Wavelength λ (px)
λ = 50 px
Angular frequency ω
ω = 2.0 rad/s
k = 2π / λ
fringe spacing ≈ λL / d
Constructive interference occurs where path difference Δr = mλ (bright fringes).

Destructive interference occurs where Δr = (m + ½)λ (dark fringes).

Slits shown as yellow dots. The barrier is at x = 40% of the canvas.
u(r,t) = A/|r−r₁| · sin(k|r−r₁|−ωt)
+ A/|r−r₂| · sin(k|r−r₂|−ωt)
